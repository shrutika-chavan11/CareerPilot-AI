System Call Differences Between Linux and xv6


1. fork()

xv6:
fork() creates a child process using a simple memory copy mechanism.

Linux:
fork() uses advanced mechanisms like copy-on-write and supports more process features.


2. exec()

xv6:
exec("program", arguments) replaces the current process with a new program.

Linux:
execve() and related functions provide more options including environment variables.


3. open()

xv6:
open() supports basic file opening with limited flags.

Linux:
open() supports permissions, access modes, and advanced file options.
